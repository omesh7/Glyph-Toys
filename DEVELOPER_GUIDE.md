# Nothing Phone (4a) Pro - Glyph Toy Developer Guide

## 📱 Hardware Context
- **Device:** Nothing Phone (4a) Pro (Release: March 2026)
- **Interface:** Glyph Matrix (Circular 13x13 Grid)
- **Addressable LEDs:** 137 independently controllable mini-LEDs.
- **Physical Controls:**
    - **Glyph Button (Power Button):**
        - **Short Press:** Cycle through active toys.
        - **Long Press:** Trigger "Action" within the current toy.
- **Sensor Integration:** Accelerometer/Gyroscope and Magnetometer are commonly used for interactive toys (e.g., Compass, Spirit Level).

## 🛠️ SDK & Development Setup
- **SDK Version:** `GlyphMatrixSDK v2.1+`
- **Device Identifier:** `Glyph.DEVICE_25111p`
- **Key Classes:**
    - `GlyphMatrixManager`: Singleton for controlling the LEDs.
    - `GlyphMatrixFrame`: Container for 13x13 (169-length) brightness arrays.
    - `GlyphMatrixService`: Base service for background execution (AOD-compatible).

## 🎯 Architecture
Glyph Toys are implemented as **Android Services** to allow them to function when the device is face-down (Glyph interface active, main screen off).

1. **Manifest Registration:** Register your service with `com.nothing.glyph.toy.SERVICE` intent filter.
2. **Lifecycle:** Nothing OS binds to your service when selected from the Glyph menu.
3. **Always-On Support:** Set `com.nothing.glyph.toy.aod_support` to `1` in metadata for low-power updates (e.g., for clocks or meditation timers).
